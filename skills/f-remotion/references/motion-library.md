# 计划确定后的 Remotion 工程能力

本库只在画面动效导演完成 `motion-plan.json` 后读取。它帮助实现已经决定的画面关系，不是创意菜单；不得因为这里有某种能力就反向修改导演方案。

## 可选能力

| 能力 | 适合表达 | 运动逻辑 | 不使用的情况 |
| --- | --- | --- | --- |
| 整词级联 | 短句中的递进重点 | 按语义词组依次淡入、轻移、轻缩放 | 长句、普通旁白、会造成阅读追赶 |
| 状态替换 | 过去→现在、错误→正确、旧方案→新方案 | 旧状态退位，新状态在同一视觉位置接管 | 两者需要同时比较 |
| 阶段轨道 | 有真实顺序的流程 | 步骤说到时进入或激活，上一项降为完成态 | 没有先后关系的并列项 |
| 分类标签组 | 少量清晰类别 | 总类先出现，子类按口播逐个补入 | 标签只是装饰或需要补写分类 |
| 视觉锚点驻留 | 多句共同解释同一概念或结论 | 主标题/核心对象保持，属性、证据和建议按台词局部更新 | 台词已经转入新的叙事任务 |
| 实体标识行 | 国家、地区、平台、组织或产品的分层/并列 | 行先进入，图标与名称在说到时逐项补入 | 图标没有可靠来源或只为装饰 |
| 确认动作 | 真正的开放、完成、通过或结论 | 结论成立时一次性落下，不循环弹跳 | 普通肯定句、同片反复出现 |
| 数字增长 | 数字本身是信息重点 | 从可信起点插值到原话数值 | 无可靠数字、数字只是编号 |
| 区间计数 | 薪资、数量或范围从下界到上界成立 | 下界保持，只有上界按口播增长并锁定单位 | 原话不是区间或端点不可靠 |
| 数据条/矩阵 | 真实可比较数据 | 条、格或列按比较关系展开 | 只有一个数字或缺少共同尺度 |
| 证据比较图 | 基准与当前值、前后值或增幅 | 先立基准，再让对照值生长，最后锁定差值/增幅 | 缺少口径、单位或可靠数值 |
| 累积堆叠 | 成本、条件、证据逐项累加 | 新项进入并推动整体重新平衡 | 只是松散列举 |
| 门槛/边界 | 受限、准入、范围变化 | 内容在边界前受阻，条件成立后通过或展开 | 仅为了画一条线 |
| 概念组装 | 多个前提共同构成一个结论 | 词块/节点汇合为核心中文概念 | 核心概念并非由前项构成 |

印章、标签、阶段高亮等小组件只是上述能力的可能外形。它们不应因为“能用”而出现；在大标题或人物表演已经完成表达时，通常删掉更好。

## 实体、图标与标志

- 先判断实体识别是否能缩短理解：地域层级、平台阵列、组织分类和产品生态通常适合；只出现一次且文字已足够时不必加图标。
- Skill 不记忆固定 Logo 清单。先从台词抽取实体，再从用户提供、项目已有或来源与使用权明确的资产中解析图标；优先官方标志，国旗可使用可靠 SVG 或 Unicode 旗帜。
- 图标始终附带文字名称或可读缩写；不能确认资产时用文字标签或中性几何符号，绝不绘制近似品牌 Logo。
- 同一实体组按口播层级逐行或逐项出现，例如“地域 → 平台 → 次级类别”；不要一次性把所有标志铺满画面。
- 卡片背景只贴合当前行，可为透明描边或局部深色表面；不得在实体组后增加全屏色底。

## 图表与数字

- 先锁定可靠事实：原话数值、单位、上下界、比较对象、共同尺度和增幅口径。缺一项就降级为普通文字，不生成图表。
- 数据图只显示台词当前需要的 1 个关系。基准先出现，对照条/柱随后生长，数字在对应词处完成，百分比或结论最后锁定。
- 区间数字让稳定下界和增长上界分工，例如“30K–60K”保持 `30K`，只将上界增长到 `60K`；不得让两个端点同时随机滚动。
- 数字动画常用约 0.7–1.2 秒，结束后稳定驻留到相关句说完；不循环、不反复归零、不添加随机跳数。
- 只有用户明确允许覆盖已有截图/B-roll 时，图表才可与素材同期出现；默认硬禁区内完全留白。

## 将导演隐喻落地

先选关系，再找空间隐喻，最后决定运动：

| 关系 | 空间隐喻 | 可尝试的 Remotion 运动 |
| --- | --- | --- |
| 聚焦 | 收束、聚合、背景退让 | 非重点降权，核心整词稳定进入 |
| 因果 | 传递、推动、落点 | 连接先建立，结果随后到位 |
| 对比 | 分栏、镜像、同位替换 | 同屏对照或旧状态退出后新状态接管 |
| 累积 | 堆叠、增长、加重 | 每项加入时重新排布或加深结论 |
| 阻断 | 门、边界、未闭合路径 | 路径停在限制节点，不做无意义扫描 |
| 解锁 | 开合、接通、由虚到实 | 条件成立后边界打开或内容转为实色 |
| 分类 | 容器、分组、归位 | 项目进入各自区域，类别必须来自原话 |
| 转折 | 换页、反向、重新着色 | 前阶段退出，后阶段接管视觉中心 |
| 实体层级 | 行、轨道、徽标槽位 | 上位类先进入，下位实体在说到时归位 |
| 数值证据 | 共同基线、量级差、端点 | 基准固定，对照增长，结论最后锁定 |

新动效至少满足：

- 只用字幕和项目上下文中的事实。
- 维持本片 `typography`、`palette`、`surfaceSystem` 与 `motionGrammar`；暗卡、细描边和旧语义色仅在计划明确选择时使用。
- 使用整词或完整信息块运动，避免暴露半个汉字。
- 主要动作时长以计划和台词为准，复杂关系按关键词拆阶段。
- 弹跳、超调、突然切断等强动作只在计划的情绪与物理法则要求时使用；无意义循环扫描和持续漂浮仍禁止。

## 组合限制

- 每个语义组只有一个主运动隐喻，并继承全片 governingMetaphor。
- 同一 `visualGroupId` 可跨多句驻留；字幕换句不是更换主运动隐喻的理由。
- 同屏最多一个主层级、一个解释层级和 3–4 个并列项。
- 强段之后根据全片节奏曲线决定克制、延续或留白，不套固定“强弱交替”公式。
- 同一小组件连续出现两次时，重新检查第二次是否必要。
- 参考片依赖暗场、镜头运动、品牌素材或 B-roll 才成立的效果，不能只抽出 UI 外壳移植。

## 从参考片学习后的存放方式

为每个新能力记录：

```text
能力名：
表达的语义关系：
必要输入：
入场 / 状态变化 / 退出：
适用镜头：
不适用条件：
是否经过用户确认：实验 / 可选 / 推荐
```

“实验”不进入默认制作；“可选”必须通过语义匹配与导演计划；只有跨项目验证并得到用户确认的能力才可标记“推荐”。单条参考片不能改变 F Remotion 的制作底线，也不能自动成为默认视觉风格。

本轮参考片提炼出的“视觉锚点驻留、实体标识行、证据比较图、区间计数”状态为“可选”：必须通过语义匹配后使用，不是每条视频的默认组件。
