# 可选动效能力与创造语法

本库扩充 F Remotion 的表达能力，但不是调用清单。先按 `semantic-matching.md` 判断，再选用、组合、变形或新写。

## 可选能力

| 能力 | 适合表达 | 运动逻辑 | 不使用的情况 |
| --- | --- | --- | --- |
| 整词级联 | 短句中的递进重点 | 按语义词组依次淡入、轻移、轻缩放 | 长句、普通旁白、会造成阅读追赶 |
| 状态替换 | 过去→现在、错误→正确、旧方案→新方案 | 旧状态退位，新状态在同一视觉位置接管 | 两者需要同时比较 |
| 阶段轨道 | 有真实顺序的流程 | 步骤说到时进入或激活，上一项降为完成态 | 没有先后关系的并列项 |
| 分类标签组 | 少量清晰类别 | 总类先出现，子类按口播逐个补入 | 标签只是装饰或需要补写分类 |
| 确认动作 | 真正的开放、完成、通过或结论 | 结论成立时一次性落下，不循环弹跳 | 普通肯定句、同片反复出现 |
| 数字增长 | 数字本身是信息重点 | 从可信起点插值到原话数值 | 无可靠数字、数字只是编号 |
| 数据条/矩阵 | 真实可比较数据 | 条、格或列按比较关系展开 | 只有一个数字或缺少共同尺度 |
| 累积堆叠 | 成本、条件、证据逐项累加 | 新项进入并推动整体重新平衡 | 只是松散列举 |
| 门槛/边界 | 受限、准入、范围变化 | 内容在边界前受阻，条件成立后通过或展开 | 仅为了画一条线 |
| 概念组装 | 多个前提共同构成一个结论 | 词块/节点汇合为核心中文概念 | 核心概念并非由前项构成 |

印章、标签、阶段高亮等小组件只是上述能力的可能外形。它们不应因为“能用”而出现；在大标题或人物表演已经完成表达时，通常删掉更好。

## 从语义生成新动效

先选关系，再找空间隐喻，最后决定运动：

| 关系 | 空间隐喻 | 可尝试的 Remotion 运动 |
| --- | --- | --- |
| 聚焦 | 收束、聚合、背景退让 | 非重点降权，核心整词稳定进入 |
| 因果 | 传递、推动、落点 | 连接先建立，结果随后到位 |
| 对比 | 分栏、镜像、同位替换 | 同屏对照或旧状态退出后新状态接管 |
| 累积 | 堆叠、增长、加重 | 每项加入时重新排布或加深结论 |
| 阻断 | 门、边界、未闭合路径 | 路径停在限制节点，不做无意义扫描 |
| 解锁 | 开合、接通、由虚到实 | 条件成立后边界打开或内容转为实色 |
| 分类 | 容器、分组、归位 | 项目进入各自区域，类别必须来自原话 |
| 转折 | 换页、反向、重新着色 | 前阶段退出，后阶段接管视觉中心 |

新动效至少满足：

- 只用字幕和项目上下文中的事实。
- 维持 V4 字体、暗卡、细描边、语义色和克制阴影。
- 使用整词或完整信息块运动，避免暴露半个汉字。
- 主要动作在约 0.3–0.6 秒内完成，复杂关系按台词拆阶段。
- 无弹跳、无循环扫描、无持续漂浮。

## 组合限制

- 每个语义组只有一个主运动隐喻。
- 同屏最多一个主层级、一个解释层级和 3–4 个并列项。
- 一段中使用了强烈的新创动效，下一段优先回到克制原型或留白。
- 同一小组件连续出现两次时，重新检查第二次是否必要。
- 参考片依赖暗场、镜头运动、品牌素材或 B-roll 才成立的效果，不能只抽出 UI 外壳移植。

## 从参考片学习后的存放方式

为每个新能力记录：

```text
能力名：
表达的语义关系：
必要输入：
入场 / 状态变化 / 退出：
适用镜头：
不适用条件：
是否经过用户确认：实验 / 可选 / 推荐
```

“实验”不进入默认制作；“可选”必须通过语义匹配；只有跨项目验证并得到用户确认的能力才可标记“推荐”。V4 基线不因单条参考片自动改变。
