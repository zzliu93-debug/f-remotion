# F Remotion V4 风格预设

本文件是 `f-remotion` 的默认视觉权威。它定义稳定的 V4 视觉基因，不把场景结构限制为 V4 已出现过的版式。

1. 设计基准

## 1. 设计基准

- 基准画布：2560×1440、16:9、60fps。
- 其他 16:9 分辨率：使用 `s = width / 2560` 等比缩放尺寸和坐标。
- 非 16:9：优先保持字号、卡片高度和人物安全区，重新排布横向宽度，不直接拉伸。
- 基准安全区：左侧约 `x=92–1042`、顶部 `y=88`、主要内容底部不超过 `y≈980`。
- 原字幕通常位于底部中央，动效必须停留在字幕安全线以上。

若人物占据左侧，将整个信息区水平镜像到右侧；文字仍保持左对齐，卡片内部结构不镜像。

## 2. 画面结构

### 透明画布与局部可读性

- Remotion 场景画布默认完全透明。不得在每个 `<Sequence>` 中放置全屏暗部渐变、语义色调、蒙版、模糊或调色层。
- 整组淡入淡出只能影响动效元素，不能改变原视频任意空白区域的亮度、色相或对比度。相邻大动效更换语义色时，原视频背景必须保持连续。
- 优先通过安全区选择、字号、字重、描边和轻微文字阴影获得可读性。背景过亮时，先换侧、缩短文案或改用局部卡片。
- 深色半透明卡片仍可使用，但它是贴合信息边界的组件表面，不是大动效背后的整片背景；面积不得无意义扩展到画布边缘。
- 历史 V4 风格板和运动样片中的单侧暗部渐变已经废弃。只参考其中的信息层级、布局密度、卡片材质和运动手感。

### 局部栏目头

栏目头是小型语境提示，不是全片进度条：

- 基准位置：`left: 92, top: 88, width: 920`。
- 左侧竖线：4×58、圆角、主蓝色、轻微光晕。
- 第一行：蓝色，28px，900 字重，约 5px 字距，如“栏目名 · 01”。
- 第二行：白色，29px，850 字重，说明本段任务。
- 第三行：灰白，18px，750 字重，约 6px 字距，必须来自真实上下文。
- 栏目头随语义组进入和退出，不做常驻总进度。

### 中文重点标题

只用于视频开头钩子或真正的核心概念：

- 主行白色，91–118px，约 950 字重。
- 强调行主蓝色，102–116px，约 950 字重。
- 左对齐，行间距紧凑，可附一条小型状态标签。
- 短词必须整词显影，不使用会暴露半个汉字的裁切动画。

### 信息卡

- 背景：`rgba(5,7,13,0.86)`。
- 边框：1px 语义色，约 53% 透明度（十六进制 alpha `88`）。
- 圆角：15px。
- 内边距：22px 28px。
- 阴影：`0 18px 48px rgba(0,0,0,0.25)`。
- 左侧强调条：4px 宽，约卡片高度的 64%，同语义色并带轻光晕。
- 普通卡高约 110–142px；定义/结论卡可达 178–220px。
- 同屏并列卡通常不超过 3–4 个。

### 连接关系

只在真实步骤、因果、分支或依赖中绘制 3px 连接线。连接线先于下一个节点完成生长，不能悬空或只作装饰。

## 3. 色彩与材质

固定主色：

| 用途 | 色值 | 语义 |
| --- | --- | --- |
| 主信息 | `#1d95ff` | 栏目、核心信息、普通状态 |
| 成功/允许 | `#42df82` | 完成、开放、确认、可用 |
| 限制/阻断 | `#ff626b` | 禁止、失败、冲突、不可用 |
| 提醒/结论 | `#f1b94d` | 成本、注意、阶段结果 |

卡片保持深色、细描边和克制阴影。不要改成亮色实心大色块，也不要添加霓虹扫描效果。

## 4. 字体层级

默认字体栈：

```text
Arial, 'Microsoft YaHei', 'PingFang SC', sans-serif
```

基准字号：

- 中文重点标题：91–118px。
- 段落大结论：58–66px。
- 定义和主卡文字：31–43px。
- 卡片副说明：20–25px。
- 栏目与状态标签：21–29px。
- 微文案：17–18px。

中文为主，英文只在原话或官方名称中出现。不得为了“科技感”把中文标题翻译成大英文。

## 5. 运动参数

基于 60fps；其他帧率按秒数换算：

- 整组入场：18 帧淡入，只作用于动效元素。
- 整组退出：最后 26 帧淡出，只作用于动效元素。
- 普通元素透明度：24–28 帧到 1。
- 普通元素位移/缩放：约 36 帧完成。
- 位移起点：常用 `-28px 14px`；横向卡片可用 `-42px 0px`。
- 缩放：`0.975 → 1`，使用 perceptual scale。
- 阶段交替：20 帧淡入/淡出，中间可保留约 8–14 帧干净间隔。
- 连接线：约 30–34 帧生长完成。
- easing：进入使用 `cubic-bezier(0.16, 1, 0.3, 1)`；退出使用 `cubic-bezier(0.7, 0, 0.84, 0)`。

默认无弹跳、无循环扫描、无持续漂浮。画面变化来自台词推进和阶段切换。

## 6. 已确认的场景语言

V4 确认了以下组合，可根据新台词选用而不是全部使用。它们是可靠起点，不是封闭模板库：

1. 中文钩子：白色主行 + 蓝色强调行 + 小型状态标签。
2. 条件分支：上位条件卡 + 连接线 + 两个或多个条件节点。
3. 两难路径：当前状态 → 红色连接 → 前置成本 → 黄色结论。
4. 步骤链：蓝/绿完成步骤 → 红色阻断步骤 → 黄色最终状态。
5. 核心揭晓：短暂中文重点标题，随后退出。
6. 定义与实例：大定义卡 + 小标题 + 逐个出现的实例卡。
7. 禁止边界：中文规则 + 红色下划线 + 禁止项卡 + 绿色安抚结论。
8. 条件结论：问题提示 + 连接线 + 带绿色确认符号的大结论卡。

长段落优先在同一语义组内从 5 切到 6，而不是让核心标题长期不变。

可以为新的语义关系设计新场景。新场景应保留本文件规定的字号层级、局部暗卡材质、透明画布、语义色、留白、整词运动和柔和进退场；它可以使用不同的空间组织、阶段关系或组件结构。

## 7. 适配规则

- 场景数量跟随完整叙事任务，不固定为 V4 的六段，也不跟随字幕条数。
- 每个元素的进入帧跟随该词的 SRT 起点；同句内部可错开 2–8 帧形成层级。
- 人物偏右时使用左侧布局；人物偏左时使用右侧布局。
- 背景过亮时先换侧、减少直排文字或改用贴合内容的局部暗卡，不添加全屏渐变。
- 并列项过多时分页或分阶段加入，不压缩成密集小字。
- 没有真实关系时不用连接线；没有真正核心概念时不用大标题。
- 辅助文案只能压缩原意，不能补写事实。
- 先按 `semantic-matching.md` 判断是否需要动效；不因为安全区有空位就填满。
- 新创动效先与无动效状态比较，只有明显提升理解或情绪时保留。

## 8. 禁止元素

- 每段一个大英文标题。
- 常驻顶部进度条或章节追踪器。
- 横扫光线、扫描线、技术网格、随机代码。
- 无来源的数字、评分、时间、编号或状态。
- 所有卡片同时弹出。
- 上一组未退出、下一组已经出现。
- 动效提前于台词完整展示。
- 台词已经转入新的视觉任务，却仍让旧主视觉无理由滞留；同一任务内的稳定驻留不在此列。
- 遮挡人物面部、关键手势或原字幕。
- 因为动效库存在某组件，就在不匹配的台词中强行展示。
- 每个大动效携带不同颜色的全屏背景、渐变或调色层。
- 仅因字幕换句或说满两句就切换一个大动效。
