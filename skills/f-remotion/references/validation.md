# 验收与渲染

## 代码检查

运行项目已有的 lint/typecheck；若没有脚本，至少执行 TypeScript 检查。确认没有 CSS transition/animation。

## 关键帧检查

每个场景至少检查：

- 进入前 1 帧。
- 进入中间帧。
- 主要信息稳定帧。
- 最后一个补充元素出现后的帧。
- 退出中间帧和下一场景首帧。

重点寻找：半字裁切、文字溢出、局部卡片过暗、卡片遮脸、字幕冲突、连接线悬空、场景交叠，以及根画布意外改变原视频亮度或色相。

```console
npx remotion still src/index.ts CompositionId analysis/check.png --frame=120 --scale=0.5
```

## 连续预览

静帧无法发现速度和衔接问题。至少渲染：

- 前 3–5 秒。
- 每个场景边界前后约 1 秒。
- 元素最多、阶段切换最多的片段。
- 至少一个不同语义色的大动效边界；盯住无组件覆盖的原视频区域，确认没有随淡入淡出发生全屏闪暗、闪亮或变色。

```console
npx remotion render src/index.ts CompositionId analysis/preview.mp4 --frames=0-240 --scale=0.375 --codec=h264 --crf=22
```

检查每个动作是否跟随实际台词，而非仅仅“看起来顺”。

## 最终检查清单

- [ ] 内置 V4 样板中的微信支付文案没有被照搬到新视频。
- [ ] 没有把英文或大标题当成每段固定模板。
- [ ] 辅助信息均有字幕或项目上下文依据。
- [ ] 相邻语义组没有意外交叠。
- [ ] 没有按字幕条数、“每两句”或固定秒数机械切换大动效；每个 `visualGroupId` 对应一个完整叙事任务。
- [ ] 关键词出现时间与口播一致。
- [ ] 长段落只在新增属性、证据、层级或转折时更新；同一概念允许稳定驻留，没有为避免静止而强行换景。
- [ ] 人物面部、手势、产品和原字幕未被关键元素遮挡。
- [ ] 用户已插入的截图、录屏、B-roll 或画中画区间没有任何新增图层，连场景根背景和退场残影也没有。
- [ ] 未在用户没有要求时生成字幕；SRT 只作为同步输入。
- [ ] 视频时长、分辨率、帧率与预期一致。
- [ ] 原音轨或新音轨存在且声道正常。
- [ ] 全片可从头到尾解码，无坏帧。
- [ ] 每个动效都有明确的台词语义理由，不是因为组件库里存在。
- [ ] 场景根画布透明；不存在全屏暗部渐变、语义调色层或随场景淡入淡出的背景。
- [ ] 国旗、平台、组织与产品图标的含义、来源和使用权明确；没有近似或虚构品牌 Logo。
- [ ] 图表和计数的数值、单位、端点、比较对象与增幅口径均可追溯，动画终值与台词一致。
- [ ] 已抽查至少一个“有动效 / 无动效”对照；新增动效确实提升理解或情绪。
- [ ] 新创场景仍保持 V4 的字体层级、卡片材质、语义色和运动手感。
- [ ] 参考片中的素材依赖效果、专有组件和话题信息没有被机械移植。

## 全片解码

系统存在 FFmpeg 时：

```console
ffmpeg -hide_banner -v info -i output.mp4 -map 0:v:0 -map 0:a:0 -f null NUL
```

Windows 项目若未配置全局 FFmpeg，可先在 `node_modules` 中定位 Remotion 或 `ffmpeg-static` 携带的可执行文件。只有当源视频确实没有音轨时，才允许省略音频映射。

## 反馈诊断

| 反馈 | 优先检查 |
| --- | --- |
| 太快 | 元素完成帧是否早于关键词、组内项目是否同时进入 |
| 太慢/疲劳 | 视觉组是否已经结束、局部信息更新是否与真实新增内容同步；不要只因秒数长就换景 |
| 背景闪烁 | 检查场景根节点是否仍有全屏渐变/调色层，或是否把背景与动效一起做整组透明度 |
| 杂乱 | 是否存在无来源装饰、同屏层级是否超过三层 |
| 不像 F Remotion | 对照内置样板检查入场顺序、留白、密度和卡片材质 |
| 模板感 | 是否连续复用同一原型、是否强行使用大标题/英文 |
| 画蛇添足 | 与无动效版本对比；检查小标签、印章、高亮、图标是否重复表达主信息 |
| 缺少创造力 | 是否在现有原型不匹配时仍硬套；是否尝试从语义关系生成空间隐喻 |
| 匹配错误 | 回到 `semantic-matching.md`，检查叙事任务、关系、强调级别和时间锚点 |
| 图标/图表缺失 | 检查台词是否出现值得识别的实体或可靠可比较数据；成立时再解析资产与可视化关系 |
| 有 bug | 入场中间帧、文本测量、遮罩边界、场景首尾帧 |
