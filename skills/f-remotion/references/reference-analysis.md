# 参考视频拆解

仅当用户明确要求更换 `f-remotion` 的内置 V4 风格、并提供新的参考片时读取本文件。默认制作流程无需外部参考视频。

## 目标

从参考片中提取可迁移的视觉规则和运动规则，同时排除只属于参考片话题的内容。不要因为参考片突出某个缩写，就推断所有目标场景都需要大英文。

## 抽帧方法

先读取元数据，再生成低频接触表定位动效段。对每组至少保留五类帧：

1. 入场前：确认原画面、安全区和背景明暗。
2. 入场中：判断淡入、位移、缩放、遮罩、弹性和元素顺序。
3. 稳定态：测量布局、字号层级、边距、卡片造型和覆盖面积。
4. 信息补充后：判断卡片/标签如何递进，以及同屏最大信息量。
5. 退场中：判断整体退出还是分层退出，是否与下一组交叠。

30fps 参考片可先每 15–30 帧采样；60fps 可先每 30–60 帧采样。发现入场或退场后，再在该区间提高采样密度。

## 三栏归类

对观察结果使用下表归类：

| 类别 | 可迁移 | 示例 |
| --- | --- | --- |
| 视觉语法 | 是 | 左侧暗部、细色描边、局部竖线、字号层级、卡片圆角 |
| 运动语法 | 是 | 轻微左移淡入、逐项出现、短遮罩揭示、整组柔和退出 |
| 话题内容 | 否 | 专有缩写、人物名字、品牌 Logo、行业专属数据、作者素材 |

当一个元素无法明确归入前两类时，默认不迁移。

## 观察记录模板

```text
组名：
参考时间：
安全区：
主要信息：
辅助信息：
入场顺序：
稳定态布局：
退场方式：
视觉语法：
不可迁移内容：
```

## 风格相似度的判断顺序

按以下顺序判断“像不像”，不要先纠结单个颜色值：

1. 信息层级是否相同。
2. 元素出现顺序和节奏是否相同。
3. 布局密度、留白与安全区是否相同。
4. 卡片材质、描边、色彩比例是否相同。
5. 字体、字号和微小装饰是否相同。

## 常见误判

- 把参考片的核心词当成所有场景的固定大标题。
- 把局部状态条误判为全片常驻进度条。
- 因为某一帧有光影变化就添加循环扫描线。
- 只看稳定帧，没有观察标题和卡片的真实出场顺序。
- 复制参考片的双语形式，却忽略目标视频完全以中文叙事。
- 为了填满空间添加字幕中不存在的数据、编号或标签。

## 输出要求

拆解完成后先输出一份内部“风格不变量”清单和“禁止照抄”清单，再开始目标视频的语义故事板。两份清单不得混在一起。
