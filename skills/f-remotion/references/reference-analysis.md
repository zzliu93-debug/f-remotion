# 参考视频拆解

当用户明确提供参考片并要求模仿、学习或扩充 Skill 能力时读取本文件。默认制作流程仍无需外部参考视频；参考片可以扩展导演的构图与运动语言，但不会改变透明合成、事实来源、中文可读性和人物安全等底线。

## 目标

从参考片中提取可迁移的视觉规则和运动机制，同时排除只属于参考片话题、素材和镜头氛围的内容。学习的目标是增加候选能力，不是增加当前视频的组件数量。

## 抽帧方法

先读取元数据，再生成一张低频接触表定位动效段。只对每种独特运动机制选一个代表组保留以下五类帧；重复机制不逐组重抽：

1. 入场前：确认原画面、安全区和背景明暗。
2. 入场中：判断淡入、位移、缩放、遮罩、弹性和元素顺序。
3. 稳定态：测量布局、字号层级、边距、卡片造型和覆盖面积。
4. 信息补充后：判断卡片/标签如何递进，以及同屏最大信息量。
5. 退场中：判断整体退出还是分层退出，是否与下一组交叠。

30fps 参考片可先每 30–60 帧采样；60fps 可先每 60–120 帧采样。只有现有帧无法判断入场顺序或退场因果时，才在一个代表区间提高采样密度；不要默认逐帧检查整片。

## 四栏归类

对观察结果使用下表归类：

| 类别 | 默认处理 | 示例 |
| --- | --- | --- |
| 视觉语法 | 提炼为导演候选，不能直接设为默认 | 栅格、留白、字号比例、图形轮廓与材质关系 |
| 运动机制 | 可加入实验候选 | 状态替换、整词级联、步骤激活、数字增长 |
| 话题内容 | 不迁移 | 专有缩写、人物名字、品牌 Logo、行业专属数据 |
| 素材/镜头依赖 | 不直接迁移 | B-roll、截图、暗场灯光、运镜、作者后期调色 |

当一个元素离开原片素材和氛围后无法独立成立时，不移植其 UI 外壳。

先把参考片中的原始截图、录屏、B-roll、画中画、字幕和后期动效分层。用户要求只看 Remotion/图形动效时，素材层只用于判断遮挡与时间，不把它的出现频率算成动效频率。

## 节奏与台词映射

不要按字幕条统计动效。先识别“完整叙事任务”，再记录其中每句对应的视觉事件：`enter`、`update`、`hold`、`exit` 或 `blank`。

- 记录大动效从哪一个关键词建立，到哪一句仍在支撑它；中间即使跨多句，也保持同一 `visualGroupId`。
- 区分整体换景和局部更新。主标题保持、标签/实体/证据逐步加入，属于一个视觉组，不是多个大动效。
- 记录真实留白。人物手势、停顿、B-roll 或过渡承担表达时，不把空白误判为“漏做”。
- 对大动效记录总驻留、主锚点稳定时间、每次局部更新和退出尾巴；总结应说明时长由什么台词任务决定，而不是只报秒数。

## 能力沉淀流程

1. 观察：记录完整入场、状态变化和退出，不只截稳定帧。
2. 抽象：把表现改写为“它让观众看见了什么关系”，去掉专有文案和素材。
3. 候选：在 `motion-library.md` 中标记为“实验”，写明适用与不适用条件。
4. 匹配：只在真实台词和镜头适合时，把机制交给画面动效导演参与三个方向的发散。
5. 对照：优先在计划、参考帧和同一条完整审片版中，与其他原创方向及无动效方案比较；不为每个方向额外渲染一套 A/B 视频。
6. 反馈：区分“能力本身不好”和“这条视频不匹配”。前者删除，后者保留为可选。
7. 提升：经过跨项目验证并由用户确认后，才标记为推荐能力。

## 风格相似度的判断顺序

按以下顺序判断“像不像”，不要先纠结单个颜色值：

1. 信息层级是否相同。
2. 元素出现顺序和节奏是否相同。
3. 布局密度、留白与安全区是否相同。
4. 卡片材质、描边、色彩比例是否相同。
5. 字体、字号和微小装饰是否相同。

## 常见误判

- 把参考片的核心词当成所有场景的固定大标题。
- 把局部状态条误判为全片常驻进度条。
- 因为某一帧有光影变化就添加循环扫描线。
- 只看稳定帧，没有观察标题和卡片的真实出场顺序。
- 把字幕换句、人物画中画或 B-roll 切换误判成新的大动效。
- 总结成“每两句一个动效”或固定秒数，而没有找出跨句的完整视觉任务。
- 复制参考片的双语形式，却忽略目标视频完全以中文叙事。
- 为了填满空间添加字幕中不存在的数据、编号或标签。
- 误以为“学会参考片”就必须在当前视频展示它的每一种机制。
- 参考片的吸引力主要来自素材和灯光，却把功劳错误归给小型 UI 组件。

## 输出要求

拆解完成后先输出三份内部清单：`F Remotion 制作底线`、`导演可选机制`、`禁止照抄/素材依赖`，并附一张按 `visualGroupId` 组织的 `台词—视觉事件—驻留理由` 节奏表。随后进入 `director/SKILL.md` 的发散流程并生成 `motion-plan.json`；参考片方案不得跳过与原创方向及无动效基线的计划层比较，但不要求额外渲染多套对照视频。
