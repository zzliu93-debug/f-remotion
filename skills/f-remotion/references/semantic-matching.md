# 台词语义匹配

本文件只决定“哪段信息值得视觉化、它完成什么叙事任务、何时变化”，包括决定不使用动效。它不决定颜色、卡片、版式或组件；先完成语义编辑，再把结果交给画面动效导演。

## 一、逐组标注

为每个语义组标注以下信息：

| 字段 | 判断 |
| --- | --- |
| 叙事任务 | 钩子、解释、举例、转折、证明、限制、结论或过渡 |
| 信息关系 | 单点、定义、顺序、因果、对比、并列、层级、边界、状态变化或数据 |
| 强调级别 | 核心、重要、辅助 |
| 情绪力度 | 平静、提醒、受阻、惊喜、确认 |
| 画面条件 | 人物位置、手势、字幕、背景明暗、可用面积 |
| 视觉必要性 | 0 留白、1 可增强、2 应可视化 |
| 视觉组 | 同一完整叙事任务使用同一 `visualGroupId`，不要按字幕条或句数编号 |
| 视觉事件 | `enter`、`update`、`hold`、`exit` 或 `blank` |
| 时间锚点 | 关键词开始、关系成立、阶段转折和退出时间 |

视觉必要性为 0 时不要勉强安排组件。人物表情、手势或原片素材已经足够时，也应降低动效强度。

## 二、先定视觉组，再定时长

- 一个大动效对应一个完整叙事任务，例如“提出概念并解释价值”“展示一组证据”“从国外需求推进到国内分层需求”。它可以只覆盖一个短语，也可以跨越多句台词。
- 不得使用“每两句一次”“每条字幕一次”或固定秒数分段。字幕换句而叙事任务未变时，保持同一视觉组。
- 对组内每句只判断五种事件：首次建立用 `enter`；新增属性、证据或层级用 `update`；继续解释同一信息用 `hold`；任务结束用 `exit`；不值得占用注意力用 `blank`。
- 大动效的结束点由最后一句仍在支撑该视觉任务的台词决定，通常在该句说完后留约 0.3–0.6 秒阅读尾巴；新的叙事任务才允许整体替换。

以下仅是起始区间，不是硬限制：

| 视觉任务 | 常见驻留 | 组内处理 |
| --- | --- | --- |
| 单次数字、结论或短促强调 | 约 1.5–3 秒 | 关键词进入，确认后退出 |
| 名称、定义或单个核心概念 | 约 3–7 秒 | 主锚点保持，解释层按需补入 |
| 论证、分层列举或多句证据 | 约 6–12 秒或更长 | 保持同一主视觉，按语义更新局部 |
| 过渡、口头语、人物表演充分 | 任意 | 留白，不补动效 |

同一主锚点长期驻留并不是问题；只有台词增加了适合可视化的新关系却完全没有更新，才需要阶段切换。

## 三、语义编辑的四种结果

每组只标记一种结果，不在此阶段选择组件：

1. **blank**：过渡、重复、口头语、人物表演充分或没有新增信息。
2. **enter**：一个新的高价值叙事任务开始，需要建立视觉锚点。
3. **update**：仍是同一任务，但新属性、证据、层级或转折值得改变局部画面。
4. **hold/exit**：继续解释时保持，任务结束时退出或交接。

这些结果描述时间与语义，不预设是卡片、标题、路径、图标还是其他形态。

## 四、常见语义线索

| 台词线索 | 需要澄清的关系 | 时间注意 |
| --- | --- | --- |
| “核心是”“真正关键” | 信息优先级是否真的发生收束 | 只在核心词说到时完成聚焦 |
| “为什么 / 因为” | 问题、原因与结果的依赖 | 不要提前展示答案 |
| “过去 / 现在 / 从…变成…” | 旧状态与新状态的差异 | 转变在对应词处成立 |
| “首先 / 然后 / 最后” | 是否存在真实先后与依赖 | 每一步在说到时才生效 |
| “比如 / 包括” | 总类与实例、并列或层级 | 数量以原话为准，不补齐版面 |
| “但是 / 不过” | 对比、例外还是语气停顿 | 真转折才触发视觉更新 |
| “不能 / 仅限 / 除外” | 边界、门槛与例外 | 限制语义成立后才强调 |
| “终于 / 已经 / 可以” | 状态是否真的完成或开放 | 完成动作只发生一次 |
| 出现可靠数字 | 数字是事实、尺度还是证据 | 数字不是重点时不升级视觉权重 |
| 国家、地区、平台或组织被并列提及 | 实体的并列、分类或层级 | 没有可靠资产时只保留真实名称 |
| 数值区间、前后量级或增幅 | 端点、共同尺度与比较口径 | 单位、端点和口径必须可追溯 |

这些是候选，不是关键词触发器。结合整段含义、语气和镜头重新判断。

## 五、交给导演的语义包

每个非留白组向导演提供：原话、叙事任务、信息关系、情绪变化、关键词帧、关系成立帧、可持续驻留范围、人物/素材安全区和为什么值得视觉化。不要提供“建议用某某卡片”，避免在创意发散前产生形态锚定。

导演仍需与无动效基线比较。若方案没有比原视频带来更清楚的关系、更准确的情绪或更有力的重点，则退回 `blank`。

## 六、时间匹配

- 元素可提前 2–6 帧建立注意，但不得提前展示完整结论。
- 一个关系只有在台词说完整后才成立时，让连接、替换或确认动作在该词处完成。
- 长段落每次画面更新都应对应新增且值得可视化的信息；没有新增视觉任务就保持稳定，不做循环动画，也不为避免“静止”而换大场景。
- 相邻语义组先退出再进入；可以保留有意的纯净留白。转折仍属于同一论证任务时使用 `Stage` 或局部更新，不要伪造两个大场景。

## 七、自检句

对每个动效写一句内部理由：

```text
因为台词表达【关系】，所以画面应在【关键词帧】让观众看见【变化】。
```

如果只能写成“更酷”“更丰富”“参考片里有”，把该组退回留白；具体运动与布局由导演阶段决定。
