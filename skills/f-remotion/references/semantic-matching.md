# 台词语义匹配

本文件负责决定“哪句话用什么动效”，包括决定不使用动效。先完成匹配，再设计画面。

## 一、逐组标注

为每个语义组标注以下信息：

| 字段 | 判断 |
| --- | --- |
| 叙事任务 | 钩子、解释、举例、转折、证明、限制、结论或过渡 |
| 信息关系 | 单点、定义、顺序、因果、对比、并列、层级、边界、状态变化或数据 |
| 强调级别 | 核心、重要、辅助 |
| 情绪力度 | 平静、提醒、受阻、惊喜、确认 |
| 画面条件 | 人物位置、手势、字幕、背景明暗、可用面积 |
| 视觉必要性 | 0 留白、1 可增强、2 应可视化 |
| 时间锚点 | 关键词开始、关系成立、阶段转折和退出时间 |

视觉必要性为 0 时不要勉强安排组件。人物表情、手势或原片素材已经足够时，也应降低动效强度。

## 二、四种结果

每组只选择一种主策略：

1. **留白**：过渡、重复、口头语或没有新增信息。
2. **复用**：现有 V4 原型准确表达关系，仅替换内容和时间。
3. **变通**：保留原型逻辑，重排方向、阶段、数量或尺寸以适应镜头。
4. **新创**：现有原型会扭曲语义时，从关系本身构造新的 Remotion 场景。

不要把“新创”理解为增加装饰。新创可以非常简单，例如让旧状态被新状态替换，而不是再加入一张卡片。

## 三、常见语义线索

| 台词线索 | 首选思路 | 注意 |
| --- | --- | --- |
| “核心是”“真正关键” | 核心揭晓、聚焦、概念组装 | 只有真核心才使用大标题 |
| “为什么 / 因为” | 问题到原因、因果路径 | 不要把疑问句和答案同时提前展示 |
| “过去 / 现在 / 从…变成…” | 状态替换、前后对比 | 优先让旧状态退出后新状态占位 |
| “首先 / 然后 / 最后” | 步骤链、阶段轨道 | 每一步在说到时进入或激活 |
| “比如 / 包括” | 逐项卡片、分组清单 | 数量以原话为准，不补齐版面 |
| “但是 / 不过” | 阶段切换、颜色与方向反转 | 转折后应改变视觉任务，不只换色 |
| “不能 / 仅限 / 除外” | 边界、禁用、门槛 | 红色只表达真实限制 |
| “终于 / 已经 / 可以” | 结果揭晓、确认状态 | 不是每次都需要印章或勾号 |
| 出现可靠数字 | 数字增长、比例条、数据对照 | 数字不是重点时保持普通文字 |

这些是候选，不是关键词触发器。结合整段含义、语气和镜头重新判断。

## 四、候选比较

新创或犹豫时至少比较：

- 一个克制方案：少元素、短动作、保留呼吸。
- 一个表现方案：使用更明确的空间关系或状态变化。
- 无动效基线：只保留原视频和字幕。

从以下维度判断，不机械求总分：

1. 是否准确表达台词关系。
2. 是否在关键词出现时完成关键变化。
3. 是否比无动效更容易理解或更有情绪。
4. 是否适合人物位置和当前背景。
5. 是否与前后场景形成节奏差异。
6. 是否增加了无来源内容或不必要注意力。

前五项没有明确收益，或第六项明显成立时，选择留白。

## 五、时间匹配

- 元素可提前 2–6 帧建立注意，但不得提前展示完整结论。
- 一个关系只有在台词说完整后才成立时，让连接、替换或确认动作在该词处完成。
- 长段落每次画面更新都应对应新增信息；没有新增信息就保持稳定，不做循环动画。
- 相邻语义组先退出再进入。转折属于同一组时使用 `Stage`，不要伪造两个交叠场景。

## 六、自检句

对每个动效写一句内部理由：

```text
因为台词表达【关系】，所以用【运动/布局】让观众看到【变化】。
```

如果理由只能写成“更酷”“更丰富”“参考片里有”，删除该动效。
