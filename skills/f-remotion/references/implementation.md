# Remotion 实现规范

## 时间轴

- 先把字幕毫秒换算成 Composition 帧，再定义 `<Sequence>`。
- 语义组默认首尾相接，不使用负间隔制造无依据的重叠。
- 元素进入帧以对应关键词为锚点，允许提前约 2–6 帧建立注意，避免提前超过 0.15 秒完整出现。
- 退出通常预留 0.35–0.5 秒；下一组在上一组视觉上不可见后再开始。
- 60fps 下，文字/卡片常用 20–38 帧进入；30fps 时按时间等比换算。

## 组内节奏

推荐顺序：

1. 局部栏目头或语境标签。
2. 本段主信息。
3. 定义、状态或连接关系。
4. 并列项逐个出现。
5. 整组退出或切换到本组下一阶段。

不要让所有元素在同一帧弹出。若稳定态持续超过约 3–5 秒且台词仍在增加新信息，增加语义状态变化或阶段切换，而不是添加无意义循环动画。

## 运动语言

使用 `useCurrentFrame()` 与 `interpolate()`，显式设置 `extrapolateLeft/Right: "clamp"`。

推荐无回弹或低回弹的进入：

```tsx
opacity: interpolate(frame, [start, start + 24], [0, 1], {
  extrapolateLeft: "clamp",
  extrapolateRight: "clamp",
  easing: Easing.bezier(0.16, 1, 0.3, 1),
}),
translate: interpolate(frame, [start, start + 34], ["-24px 10px", "0px 0px"], {
  extrapolateLeft: "clamp",
  extrapolateRight: "clamp",
  easing: Easing.bezier(0.16, 1, 0.3, 1),
})
```

- 短标题：整词淡入 + 轻位移 + 0.97→1 的感知缩放。
- 长句：内置 V4 预设默认不做打字/遮罩；只有用户明确要求时才添加。
- 卡片：淡入 + 8–24px 位移；同组项目错开约 6–16 帧或按字幕分别进入。
- 连接线：在目标节点进入前生长完成。
- 退出：整体淡出并轻微回撤，避免复杂散场抢走台词注意。

## 布局与层级

- 根据人物位置选择左侧或右侧安全区，不固定使用左侧。
- 画中动效不要覆盖原字幕；至少保留字幕背景框以上一段安全距离。
- 同屏优先保持 1 个主层级、1 个解释层级、最多 3–4 个并列项。
- 主标题、定义面板和卡片组不必同时存在；用阶段切换控制密度。
- 暗部渐变只服务于可读性，透明度随背景调整，不要遮黑整幅视频。
- 卡片使用统一圆角、细描边和克制阴影；色彩由语义决定。

## 组件结构

建议至少拆分：

- `OverlayShell`：可读性渐变、色调、整组进退场。
- `SectionHeader`：局部栏目头，可选而非常驻模板。
- `Stage`：同一语义组内部的阶段切换。
- `FadeMove`：文字和一般元素进入。
- `InfoPanel`：可变内容卡片。
- `GrowLine`：真实的顺序/因果/分支关系。
- 业务场景组件：只负责文案、布局和时间点。

当场景变多时，每个场景单独建文件；基础原语与项目文案分离。

## 文本与素材

- 中文字体必须确认机器和渲染环境可用；必要时随项目放入本地字体。
- 对长中文做真实尺寸检查，避免只凭字符数估宽。
- 图标优先使用项目已有 SVG、简单几何或文本符号；不要擅自抓取品牌图标。
- 保留原视频音轨时使用 `<Video>`，确认最终输出仍包含音频流。

## 版本策略

输出使用递增文件名，如 `video-effects-v2.mp4`。不要覆盖用户已确认版本；代码修改前检查工作区已有变更并保留无关内容。
